블루의 해답 노트 / 수정 안내

index.html을 열어 사용합니다. 별도 설치나 빌드는 없습니다.
이 사이트는 세계관 밖의 해답 안내서입니다. 실제 세계관 속 블루가 모든 정보를 소유한다는 설정은 아닙니다.

config.js
- standing.url: 오른쪽(모바일에서는 하단)의 블루 스탠딩 이미지 직접 HTTPS URL.
- secret.url: Ctrl+Shift+I를 누를 때 등장하는 코스튬 블루 이미지 URL.
- GIF, animated WebP, PNG, JPG 지원. 투명 배경 세로 스탠딩 권장, contain으로 잘림 없이 자동 맞춤.
- 빈 URL이나 불러오기 실패 시 assets/silhouette.svg 회색 실루엣 표시.
- secretLine: 이벤트 대사.
- secretDuration: 이벤트 표시 시간(기본 6500ms), 이후 약 0.5초간 사라짐.
- links: 다섯 기존 사이트 링크. 직접 배포한 최신 주소로 바꾸세요.
  기관과 직원 포털의 최신 수정본은 ZIP으로 제공했으므로, 그 ZIP을 배포한 뒤 해당 URL로 변경해야 최신 기록과 연출로 이어집니다.

notes.js
- title/place: 제목/장소
- direct: 기믹 발동 방법, 입력값을 직접 안내.
- indirect: 진실을 확정하지 않고 독자가 추론할 질문과 비교 관점.
- aside: 블루의 짧은 여백 메모.
- site: config.js links의 키.

UI
- 목차 버튼으로 해당 장을 펼치고 이동.
- 장별 '찾아가는 방법'은 처음에 닫혀 있음. 원할 때만 조작법 공개.
- 읽음 표시는 같은 브라우저의 로컬 저장소에 보존. 버튼을 다시 누르면 해제.
- '모두 접어 두기'는 모든 장과 조작법을 닫음.
- Ctrl+Shift+I: 화면 블러 + 블루 이미지와 대사, 자동 복귀. Esc로도 닫기 가능.
- 연속 키 입력은 중복 실행하지 않음. 닫히면 다시 실행 가능.
- 페이지에 키보드 초점이 필요합니다. 브라우저가 키를 먼저 처리하면 개발자 도구가 열릴 수 있습니다.
- 키보드 없는 모바일에는 별도 단축키 대체 버튼을 두지 않았습니다.
- 스크롤 위치와 펼친 장은 이벤트 뒤에도 유지됩니다.
